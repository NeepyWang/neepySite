# 听见华夏 · 中国古代民族乐器 AI 综合体验馆

纯静态交互站点，打开即用，无需安装、无需登录，不依赖外部 CDN。

## 页面

| 页面 | 目录 | 内容 |
| --- | --- | --- |
| 交互网页入口 | `/` | 三张卡片，进入下列体验页 |
| 八音分类体验馆 | `bayin-experience/` | 金、石、土、木、丝、竹、匏、革八件乐器，点击聆听音色、连奏八音，附「听辨音色」小游戏三档难度 |
| 九霄环佩古琴 3D | `jiuxiao-huanpei/` | 唐代「九霄环佩」琴三维细部赏析，可拖动旋转、滚轮缩放，六种视角与二十处细部索引 |
| 钟磬和鸣 | `zhongqing-heming/` | 曾侯乙编钟、编磬模拟演奏，一键切换乐器，点击钟体或琴键发声，可辨正鼓音、侧鼓音与音高映射 |

## 本地预览

直接打开根目录 `index.html` 即可；若浏览器限制本地文件加载，可在仓库根目录启动静态服务：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 部署说明

- 全部页面与素材（图片、音频数据、3D 逻辑）都在仓库内，路径均为相对路径，可直接作为静态站点托管。
- GitHub Pages：把源设为 `main` 分支根目录即可，站点地址为 `https://neepywang.github.io/neepySite/`。
- 钟磬页的音频以 base64 内嵌在 `zhongqing-heming/bell-audio-data.js` 与 `qing-audio-data.js`，按需加载，首次点击乐器时才读取。
